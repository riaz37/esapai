# Service Page — Award-Winning Inspiration by Section

Reference list of award-winning and high-converting websites you can use for each section of the service page. Links are to Awwwards, Landing Page Elements, CSS Design Awards, and FWA where relevant.

## 1. Hero

**What to look for:** Clear value line, minimal clutter, optional motion or 3D; service name + one-line promise.

| Site / element | Platform | What to take |
|----------------|----------|--------------|
| **Depict.ai** (full site) | Awwwards | Clean hero, strong typography, scroll-led narrative. |
| **Vention** – Hero Section (Mobile) | Awwwards | Dark, minimal, CTA graphics. [Inspiration](https://www.awwwards.com/inspiration/hero-section-mobile-vention-website-1) |
| **All You Can Design** – Hero Section | Awwwards | Hero + image balance. [Inspiration](https://www.awwwards.com/inspiration/hero-section) |
| **Carl Gordon Portfolio** – Interactive 3D Hero | Awwwards | 3D, gradient, animation (use sparingly for service). [Inspiration](https://www.awwwards.com/inspiration/interactive-3d-hero-section-carl-gordon-portfolio-c-2024) |
| **Igloo Inc** | Awwwards Site of the Year 2024 | Overall craft and hierarchy. |
| **Clearstreet** | CSS Design Awards 2024 nominee (8.73) | Typography, scroll, fintech/professional tone. [CSS DA](https://www.cssdesignawards.com/woty2024/sites/clearstreet) |
